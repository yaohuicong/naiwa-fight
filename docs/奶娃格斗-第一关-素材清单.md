# 奶娃格斗 · 第一关 素材清单（v1）

> **修订日**：2026-11-05 · **范围**：只做第一关 · **小兵**：豆奶、精锐近战（叉腰奶兵）· **Boss**：奶豪
> **目标观感**：横版像素清版过关。参考图借鉴的是**画面构成和氛围**：多层视差的雨夜场景、暖色光源加湿地反光、屏幕四角 HUD、橙色命中碎片。**不照搬**参考图的具体美术和 UI 图样，全部按奶娃世界观重新设计。
> **场景主题**：沿用 PRD 的远期方向「A′ 黑雨霓虹死巷」。如果想改成参考图那种雨中古桥风格，只需替换第 1 节的场景提示词，其余不变。
> **用法**：按表里的「云盘文件名」生成后上传到 Google Drive「奶娃」（可以建子文件夹：`场景/`、`UI/`、`FX/`、`音频/`）。上传后告诉我，我从云盘拉取并接入。
> **状态**：✅ 云盘已有，可直接用 · ⚠️ 已有但需重做或补传 · ❌ 缺失
> **优先级**：**P0** 做出参考图观感必需 · **P1** 明显加分 · **P2** 锦上添花

## 0. 统一规格（所有美术素材都要遵守）

| 项 | 规格 |
|---|---|
| 画面分辨率 | 游戏画面 **1920×1080**（逻辑 960×540 ×2）。下表尺寸均按 1920×1080 给出 |
| 关卡长度 | 3 屏宽 = **5760 px**（起点巷口 → 波次 1 → 波次 2 → Boss 场地） |
| 地面线 | 画面 **y = 900**（距顶 83%），角色脚底踩在这条线上；可行走地面带为 y 900–1080 |
| 角色身高参考 | 奶察 ≈ 330 px · 豆奶 ≈ 265 · 精锐 ≈ 295 · 奶豪 ≈ 410（场景里的门、窗、路灯按这个比例画） |
| 画风 | 粗颗粒像素风，与现有「奶察-待机-6帧表」一致（大约 4 px 一个像素点），描边清晰 |
| 色调 | 冷色雨夜：蓝灰、墨青、深紫为主；暖色只给光源（路灯、霓虹、店招），湿地面有光源倒影 |
| 透明底 | 除最远天空层外一律用透明 PNG。**不要用黑色或近黑色做抠图键色**（奶豪基础帧就是这样被抠坏的），先在品红 #FF00FF 或绿幕上生成再抠 |
| 帧表 | 同一张只画一个动作：左→右、上→下，等格，脚底基准对齐，无文字、水印、分格线 |
| 无缝平铺 | 标了「横向无缝」的图，左右边缘要能首尾相接 |

**通用风格前缀**（复制到下面每条提示词的最前面）：

```
像素艺术，2D 横版清版动作游戏，雨夜，冷色蓝灰调，薄雾，湿漉漉的反光地面，少量暖色光源，粗颗粒像素点，清晰描边，无文字，无水印，
```
