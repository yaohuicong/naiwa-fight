## 三、需要重新生成的素材（附提示词）

### 3.0 这次素材坏在哪里，提示词里一定要加上

奶豪的 **KO、起身、普攻** 三套帧在源图里就坏了，云盘上的「帧表」和「单帧 zip」都一样。原因是生成器按等宽格子切图，但角色动作比格子宽（踢出去的脚、被打飞的身体），于是：

- 身体中间出现一条条错位的竖条（KO 第 3–6 帧、起身第 1–3 帧）
- 踢腿的脚被格线截断，白色冲击弧线跑到了下一格（普攻第 3、4 帧）

所以下面每条角色提示词的末尾都要加上这段**排版要求**：

```
排版要求：只画一个动作，横向排成一行 N 格，每格大小相同（Boss 每格 420×440 像素，小兵和奶察每格 360×400 像素），角色完整地画在格子中央，四周至少留 32 像素透明边距；任何部位（伸出去的脚、拳头、特效弧线、星星）都不能越过格线，宁可把角色画小一点；相邻两格之间不能有残片或重叠；所有格子脚底在同一条水平线上。背景纯品红 #FF00FF（便于抠图），不要文字、水印、分格线、地面阴影。导出一整张横向帧表 PNG。
```

**角色外形要统一**：奶豪以「待机-v2」为准，**白色耳机戴在兜帽外面**。现在独舞、打字、黑客屏、黑洞、起身这几套没有耳机，战斗中耳机会一会儿有、一会儿没有。

## 四、需要写代码的设计项（素材到了我来做）

按投入产出比排序。做完这些，再加上第三节的素材，就能到 80 分。

1. **道具系统**（依赖素材 8、9、10）：每段路放 1–2 个可破坏物；每波清场后掉一杯奶茶。现在整关没有回血手段，打 Boss 时血量是多少就是多少，容错太低
2. **闪避翻滚**（依赖素材 5）：Shift + 方向，或手柄 RB + 方向；无敌 12 帧，冷却 0.5 秒
3. **奶豪第四招肚皮冲撞**（依赖素材 6）：玩家离开 300 像素以上时概率触发，起手有 0.6 秒蓄力提示
4. **开场一屏的小遭遇**：现在从起点走到第一波要 6 秒左右，路上什么都没有。可以在巷口放 2 个不锁屏的豆奶，教玩家打碎麦克风、跳麦克风
5. **精锐有精锐的样子**（依赖素材 7）：受击 3 次以内不会硬直（轻量霸体），会防反一次，血量从 220 提到 300
6. **跳跃攻击专用帧**（依赖素材 4）：接入后空中攻击判定改为向下劈，能打到倒地的敌人

## 五、保持现状、不建议改的地方

- **打击手感**：顿帧、受击抖动、重击震屏、击杀慢动作和像素伤害数字，已经接近《怒之铁拳 4》的水准，不建议再加特效，加多了会糊
- **单一平面**：PRD 定的是纯横版（不能上下走位）。这是取舍，不是缺陷。代价是被两面夹击时更危险，所以第四节的闪避翻滚很重要
- **雨夜场景和四角 HUD**：画面观感是目前最强的部分。唯一的问题是可读性（暗色 Boss 配暗色背景），这一点已经靠紫色描边和水波描边解决

### 6.2 第四节的设计项

| 设计项 | 结果 |
|---|---|
| 1 道具系统 | ✅ 5 个可破坏物：巷口纸箱掉能量奶瓶，第一波路段一杯小奶茶，第二波路段一杯小奶茶和一瓶能量，Boss 场地垃圾桶掉大杯奶茶；每波清场掉一杯小奶茶。满血时走过奶茶不会吃掉 |
| 2 闪避翻滚 | ✅ S / ↓（手柄 LB；狂笑改到 LT）。滚约 110 像素，第 2–20 tick 无敌；任何地面招式出招 12 tick 后可以翻滚取消。**翻滚无敌时被扫到的招式算闪掉**，无敌结束后不会再补打 |
| 3 奶豪肚皮冲撞 | ✅ 玩家离开 300 像素以上时有一半概率出招，冷却 7 秒。头顶冒红色「！」+ 0.6 秒蓄力，然后冲刺约 340 像素，霸体，命中 90 伤害并击倒。第一次出招会提示「按 S 翻滚穿过去」。实测：冲刺中奶豪离你 170–330 像素时翻滚（朝哪边都行）都能躲开 |

| 5 精锐 | ✅ 血量 220 → 300；出拳蓄力时轻击打不断（头顶冒「硬抗！」），重击、冲刺、三段收尾、大招能打断。「防反一次」没有做，现在这样已经够有区别 |
| 6 跳跃攻击 | ✅ 换成下劈专用帧。「能打到倒地的敌人」没有做：倒地无敌是清版游戏的惯例，打倒地敌人反而容易无限连 |

另外：独舞水波改成在奶豪落脚溅水花的第 3、11 帧发出，两圈间隔约 1.1 秒和 2.1 秒交替。实测提前 0.05–0.4 秒起跳都能躲开，也可以翻滚穿过。
