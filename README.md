# 奶娃格斗 · 第一关

按《奶娃格斗-第一关-PRD.md》实现的横版像素格斗原型。使用 Phaser 3、TypeScript 和 Vite。所有素材都来自 Google Drive「奶娃」文件夹。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 输出到 dist/，可直接静态部署
```

调试入口：`?start=w1` 跳过标题，`?start=w2` 直接跳到第二波，`?start=boss` 直接进 Boss 战。

## 操作

| 动作 | 键 |
|---|---|
| 移动 | A / D 或 ← / → |
| 跑 | 按住 Shift，或双击方向键 |
| 跳 | W / 空格 / K / ↑ |
| 轻击（三段连击，空中可出一次） | J |
| 冲刺攻击 | 跑动中按 J |
| 重击（两段） | I / U |
| 翻滚闪避（中段无敌，能穿过冲撞和水波） | S / ↓ |
| 大招：奶狗骑乘冲锋（能量满） | L / O |
| 狂笑 | ; |
| 暂停 / 重开 / 回标题 | Esc 或 P / R / T |
| 调试框（受击框、攻击判定、PLACEHOLDER 标签） | F1 |
| 静音 | M |

支持标准手柄：A 跳 · X 轻击 · Y 重击 · B 大招 · LB 翻滚 · RB/RT 跑 · LT 狂笑 · Start 暂停，左摇杆或十字键移动（推到底就是跑）。

路上的垃圾桶、纸箱打两下（或重击一下）就碎，会掉奶茶（回血）或能量奶瓶；满血时走过奶茶不会吃掉，可以留着打 Boss 时再回来拿。

## 调手感

数值都在 `src/config/`（PRD §10.2），改完保存即可热更新：

- `balance.json`：角色属性；每招的帧序列、判定框、伤害、HitStop、硬直、击退、击倒值、取消窗口；输入缓冲；震屏；慢动作
- `waves.json`：关卡长度、波次触发点、锁屏区间、刷怪顺序与延迟
- `boss.json`：奶豪的属性、踢击、阶段阈值、雨中独舞和终端装逼的时间轴、援军

时间单位是 tick（1/60 秒），游戏逻辑以固定 60Hz 运行。HitStop 期间整个世界冻结，只有受击者抖动。

## 关卡与场景

关卡 4 屏宽，正好对应场景的 4 段：A 巷口（起点）→ B 便利店（第一波）→ C 后巷（第二波）→ D 网咖门口（Boss）。
每段的锁屏区间就是这一段的范围。视差层：天空固定 · 远景 0.15 · 中景 0.8（段间渐变衔接）· 雾 0.45 · 近景/地面/道具 1.0 · 前景 1.15（只占画面最下方、角色脚底以下，画在角色前面）。
开场巷口有两个不锁屏的豆奶；每波清场掉一杯小奶茶；Boss 场地里有一个藏着大杯奶茶的垃圾桶。

## 素材流程

仓库里只有游戏要用的成品素材（`public/assets/`），`git clone` 后 `npm install && npm run dev` 就能玩。
下面这些处理脚本要读的原始素材（`drive-assets/`）在作者的 Google Drive「奶娃」里，不随仓库发布；
从云盘拉取素材的辅助脚本也只留在本地。

```
drive-assets/          第一批：帧表 PNG、Boss 技能单帧 ZIP、梗音
drive-assets/v2/       2026-11-05 批：场景 / UI / FX / 音频 / 小兵 / 奶豪-基础帧-v2 / 角色-P1
drive-assets/v3/       2026-11-06「审查重做」批：p0（奶豪 KO/起身/普攻）· p1（跳攻、翻滚、肚皮冲撞、
                       精锐 5 套、可破坏物、掉落物）· p2（奶豪 4 套技能帧、前景、标题主视觉）· sfx
drive-assets/fonts/    Fusion Pixel 12px 中文（官方 Release v2026.10.25，SIL OFL）

npm run sprites   tools/build_sprites.py  角色帧：切帧 → 去相邻帧碎片、去品红抠图残边 → 对齐脚底
                                          → 按站姿统一身高 → 奶豪加描边 → 256 色量化
                                          （v3 帧表是固定格、四周留 32px 透明边，直接按格切）
npm run stage     tools/build_stage.py    场景去残边并裁到可见区域、中景段间渐变、UI 框裁切与
                                          血条凹槽测量、拖影去黑芯 → public/assets/{stage,ui,fx} + assets_v2.json
npm run font      tools/subset_font.mjs   把像素字体裁到代码里实际用到的字（约 500 字，18KB）
```

改了界面文字后要重新运行 `npm run font`，否则新增的字会回退到系统字体。

## 渲染

有 WebGL 时以 1920×1080 渲染；没有 GPU 的环境（例如部分内嵌浏览器）自动回退到 Canvas，并以 960×540 渲染以保证帧率。
所有界面仍按 1920×1080 布局，由摄像机统一缩放。Canvas 模式下受击闪白改用白色剪影贴图，雨只保留一层。

## 当前占位

- 冲刺攻击（跑动中按 J）暂借重击第 5–10 帧
- 豆奶死亡仍用第一批的帧（第 1–3 帧脚下有地面阴影）：重做版背景是半透明紫色、姿势顺序乱，没法用
- 黑客屏、黑洞的独立特效层仍用第一批的 FX 帧（新帧表只重画了奶豪本人）
- 「黑客绿码」可选包未上传，黑客屏的代码雨仍由程序生成

素材清单见 [docs/奶娃格斗-第一关-素材清单.md](docs/奶娃格斗-第一关-素材清单.md)（云盘「奶娃」里有同名文件）。

## 代码结构

```
src/config/      数值表（JSON）
src/game/        actor（基类：物理、击退、受击、动画）· player · enemies · boss
                 combat（HitStop / 震屏 / 判定结算）· fx（火花、拖影、水波、黑洞、伤害数字、小血条）
                 director（波次、锁屏、检查点）· input（缓冲）· audio（梗音 / 音效 / BGM）
                 stageArt（视差场景与道具）· assets（素材清单、特效动画、渲染分辨率）
src/scenes/      Boot · Title · Backdrop · Stage · UI（HUD 和覆盖层）· Credits
```
